# Arabic AI-Generated Text Classification

## About the project
This project explores how machine learning and deep learning methods can classify Arabic text as AI-generated or human-written.

I prepared and cleaned the text data, then compared several approaches, including TF-IDF with traditional machine learning models, an LSTM network, and AraBERT.

## What I learned
This project gave me practical experience in Arabic text preprocessing, feature extraction, model training, and comparing classification results.

## Tools used
Python, pandas, NLTK, scikit-learn, TensorFlow/Keras, and Hugging Face Transformers.

## Important note
This is an educational experiment. Its predictions are not proof that a text was written by AI or by a human.
